title: Usage
---

Ollama's API responses include metrics that can be used for measuring performance and model usage:

* `total_duration`: How long the response took to generate
* `load_duration`: How long the model took to load
* `prompt_eval_count`: How many input tokens were in the prompt
* `prompt_eval_cached_count`: How many prompt tokens were read from the cache
* `prompt_eval_duration`: How long it took to evaluate the uncached prompt tokens
* `eval_count`: How many output tokens were processes
* `eval_duration`: How long it took to generate the output tokens
* `gpu_energy`: How much energy the model's GPUs drew while evaluating the prompt and generating the output tokens

All timing values are measured in nanoseconds, and energy is measured in joules.

`gpu_energy` is the energy of the whole GPU board, including what it draws while idle. Ollama can't see other programs using the GPU, so their draw is counted too. It is only reported on Linux, for NVIDIA GPUs with an energy counter, and only when the model runs on the GPU. It is left out when another request or model in Ollama used the same GPUs at the same time, because the board's draw can't be split between them. Models on the MLX engine don't report it, and their work on a shared GPU isn't noticed. Some GPUs update their counter only every 100 ms, so for very short responses the value is rough or missing.

## Example response

For endpoints that return usage metrics, the response body will include the usage fields. For example, a non-streaming call to `/api/generate` may return the following response:

```json
{
  "model": "gemma4",
  "created_at": "2025-10-17T23:14:07.414671Z",
  "response": "Hello! How can I help you today?",
  "done": true,
  "done_reason": "stop",
  "total_duration": 174560334,
  "load_duration": 101397084,
  "prompt_eval_count": 11,
  "prompt_eval_cached_count": 8,
  "prompt_eval_duration": 13074791,
  "eval_count": 18,
  "eval_duration": 52479709
}
```

For endpoints that return **streaming responses**, usage fields are included as part of the final chunk, where `done` is `true`.
